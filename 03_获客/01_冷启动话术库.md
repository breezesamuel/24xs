# 冷启动获客话术库（可直接抄用）

> 数据支撑：`99_产出/获客名单/触达队列_A档_*.csv`（每条潜客已生成个性化文案）
> 原则：**先给价值，后谈合作**。所有话术里，"我是谁"永远排在最后。

---

## 零、铁律（违反越多，回复率越低）

1. **一天 60 条，分 4 批（早 10 条 / 午 10 条 / 晚 30 条）**。一次性发 60 条会被限流。
2. **第一条不能说"我是做 AI 的"**。要说他能看到的事实。
3. **不约会议**。要一个"回一个词"的极低成本动作。
4. **不群发**。每条至少有一处是他独有的信息（他的平台、他的痛点、他的数据）。
5. **48 小时内不重复触达**。被拉黑比不成交更贵。
6. **一条只讲一个场景。** 讲三个等于什么都没讲。

---

## 一、首次触达：私信版（主力渠道）

```
看到{城市}{行业}公司在{平台}上{可观察信号}。

先说结论，不自我介绍：你这条链路大概率断在中间——
客户会问的那些问题，机器读不到，所以搜索引擎和 AI 都推荐你的同行。

我整理了一份「{行业}获客自检表」，12 项，每项对应一个能核验的数据。
不留资、不加微信，你回我「自检」我直接发。

（{你的名字}）
```

**为什么这样写**：
- 第一句 = 可观察事实 → 证明你看过他
- 第二句 = 结论 → 证明你有判断力
- 第三句 = 零成本动作 → 降低回复门槛
- 最后才是身份

**"可观察信号"从哪来**（必须有真的，这是不能造假的部分）：
- 公众号最近一条是 X 天前
- 官网没有 Schema / 没有任何第三方提及
- 抖音 200 条视频但没有一条挂链接
- 点评只有 87 条评论，最近一条是 8 个月前
- 招聘 JD 里还写着"熟练使用 Word/Excel"
- 他在小红书发了"有没有靠谱的{行业}"的求助贴

---

## 二、首次触达：邮件版（企业官网/搜索渠道）

```
主题：{城市}{公司名}｜一份 {行业} 自购清单，12 项，附判断依据

{称呼}，你好：

我不介绍公司，先说我的判断。

我看了{公司名}在{平台}的内容更新情况（最近一次是 {日期}），
结合你这个行业的公开数据，我的判断是：
潜在客户现在向 AI 咨询时会看到同行，看不到你。原因不在营销投入，
在于客户真实会问的那 {N} 个问题，你的官网和内容里没有可被机器引用的答案。

我能做的一步：{具体动作}。预期效果：{具体指标}。

我先发一份自检表（12 项，每项都有可核验口径），你看完再决定要不要聊。

回复「要」我就发。或者直接问我第 3 项和第 7 项，这两项我判断是大多数{行业}丢分最多的地方。

{署名}
{公司}
```

**邮件的三个硬要求**：
1. 主题行必须让收件人**在手机上也能读懂**，包含"免费/清单"类词提高打开率
2. 正文首行就要出现**他公司名或他城市**
3. 全文 ≤ 200 字（超过 300 字打开率断崖下跌）

## 三、电话开场白（60 秒内挂断也算成功）

```
您好，请问是{公司}吗？我找{称呼}。

我叫{名字}，做{行业}方向的。不占用您太久，就三句话：

第一，我看到贵司在{平台}上{可观察信号}；
第二，这通常意味着客户问 AI 的时候看不到您；
第三，我这边有一份{行业}自检表，12 项口径，免费。

如果这个话题跟您无关，我现在就挂。

……

（听）

好的，那我发到{微信/邮箱}？您回我一个「收到」就行，不用回我问题。
```

**为什么要允许自己被挂断**：说"如果不相关我现在就挂"，通过率反而更高，
因为对方知道没有陷阱，不会紧张应对推销。而且**真被挂断也是一种有效筛选**。

## 四、三次跟进节奏

| 次序 | 时间 | 目的 | 话术 |
|---|---|---|---|
| 第 2 次 | 3 天后 | 给一个新的价值点，不重复 | 见下 |
| 第 3 次 | 7 天后 | **给一个让他自己动手的方法**，不要求任何东西 | 见下 |
| 冷却 | 14 天后 | 停止。进 90 天冷却池 | — |

### 第 2 次（3 天后）
```
{公司名}，自检表发你了。

先看第 3 项和第 7 项——这两项是我见过的{行业}里丢分最多的地方。

如果这两项你们已经做得很扎实，那你的问题大概率不在获客，
而在转化路径（客户看了但不下单）。这块我可以另发一份对照表。

需要的话回一句「对照表」。
```

### 第 3 次（7 天后）
```
{公司名}，最后跟进一次，不回了我就不打扰了。

留一个东西给你，你可以现在就做，不花钱：

打开 DeepSeek、豆包、Kimi 各问 3 个你的客户真实会问的问题，
截图看看有没有你。

90% 的老板第一次做完会沉默一会儿——那就是答案。

需要我帮你看截图，回「截图」。
```

**第 3 次的价值**：它**不要求任何东西**，只给一个 3 分钟能完成的自查动作。
这是回复率最高的一次触达，因为它没有任何"交换"的味道。

## 五、常见拒绝的应对（逐条照抄）

| 对方说 | 你回 | 底层逻辑 |
|---|---|---|
| "暂时不需要" | "好的。那我把自检表发你，不打扰。以后你想看看自己在 AI 里到底存不存在，随时找我。" | 不施压，留下低成本再联系的理由 |
| "已经在做了" | "那更该看一下——'在做'和'能被 AI 读到'是两件事。你做的那批内容，问 AI 的时候能出现吗？回我一个真实问题，我帮你看一眼。" | 立刻把抽象变具体 |
| "太贵了" | "理解。那先不谈钱。我按你刚才说的做一次 60 题的现状检测，出一页纸结论，你看完再判断值不值。这个不收费。" | 把价格对话降级为价值对话 |
| "发个资料我看看" | "可以。但我发的是通稿，对谁都一样。更好的做法：我按你的情况做一页纸的针对性判断，5 分钟的事。你要的话我就做。" | **拒绝通稿**是抬高价值最有效的一招 |
| "我问问合伙人" | "行。方便的话我给你两样东西你带过去：① 我给你的这页纸；② 我签过的{行业}案例（脱敏）。你不用替我说话，数字会说话。" | 给客户"带得出去的材料" |
| "没预算" | "那我们先不谈合作。你自己按自检表查一遍，把查出来的三个问题记下来，半年后再看。如果到时候数字变好了，你心里会有数。" | 长期低频培育 |
| 已读不回 | 不再追。7 天后换渠道（换平台重新触达），文案换成"刚看到你们最近{可观察的新信号}" | 换角度，不换人 |

## 六、回复后的推进路径（最高优先级）

一旦对方回复，按这个顺序走，**不要跳步**：

```
回复 → ① 发自检表（不发方案）→ ② 帮他看第 3、7 项（免费，30 分钟视频/语音）
     → ③ 出 1 页纸针对性判断（免费）→ ④ 提出付费体检（半天，5000-20000）
     → ⑤ 体检做完 → ⑥ 出正式方案（付费）
```

**关键**：**不要在第 ① 步就发方案。** 方案是给已经相信你的人看的。
在对方还没拿到任何价值之前发方案，等于免费给竞争对手做了尽调。

**转化率经验值**：
- 发自检表后继续对话：30%
- 看完自检表愿意视频：15%
- 愿意做付费体检：5%
- 体检后成交全案：30-50%

所以 **100 条触达 → 5 个体检 → 1.5-2.5 个成交**。按平均 3.5 万算，
**100 条私信 ≈ 5-8 万收入**。这就是为什么"每天 60 条"是唯一不能省的动作。

## 七、批量执行检查表

每天：
- [ ] 早 9:30 发 15 条（活跃时段）
- [ ] 午 12:30 发 15 条
- [ ] 晚 20:00 发 30 条
- [ ] 记录每条的状态（已发 / 已读 / 已回 / 已挂）
- [ ] 已回的**当天必须回复**（超过 24 小时回复率减半）
- [ ] 第 3 天发跟进
- [ ] 第 7 天发最后跟进
- [ ] 每周五复盘一个失败对话，把原因写进话术库

**回复率健康线：≥ 8%。** 低于 3% 说明人群选错了或文案太像广告，
**先改文案，不要加量**。加量只会更快地浪费名单。
