# ICP 画像与名单获取方法

> 名单已由 `python cli.py leads` 生成结构化目标池，导出在 `99_产出/获客名单/`。
> 本文解决的是：**这些"实体特征"怎么变成真实的公司名和联系人。**

---

## 一、ICP 优先级（必须先做一个行业，不是五个）

| 优先级 | 行业 | 客单价 | 决策链 | 理由 | 建议 |
|---|---|---|---|---|---|
| **P0** | 家装/装修 | 3.5 万 | 老板本人 | 客单价高、老板能拍板、内容需求密集、决策快（21 天） | ✅ **首选** |
| **P0** | 跨境电商 | 12 万 | 运营负责人 | 痛点明确（ROAS 下滑）、有英文站、预算充足 | ✅ 备选 |
| P1 | 律师/律所 | 8 万 | 主任 | 付费意愿高、内容依赖强 | 合规要求高 |
| P1 | 本地生活 | 1.2 万 | 店主 | 单店预算低 | 只能走标准小包 + 渠道分销 |
| P2 | 制造业 | 25 万 | 市场总监 | 客单最高 | 但决策链 60 天，6 个月窗口太紧 |

**为什么先做家装/装修**：
1. 老板本人决策，不需要过采购、过 IT、过财务
2. 客单价 3-8 万，报价不需要长销售周期
3. 痛点极其具体（"客户比价 3 个月，销售被反复问同样的问题"），一句话就能说清价值
4. 老板 IP 需求强 → 内容服务好卖
5. 老板普遍会为"能省销售时间"付费

## 二、名单获取：四条路（按成本从低到高）

### 路线 1：公开搜索（免费，今天就能做）
搜索式样（每个行业跑一遍，保存为 CSV）：

| 目标 | 搜索关键词 | 提取字段 |
|---|---|---|
| 家装公司 | `{城市} 家装公司 抖音`、`{城市} 装修 公司 官网`、`{城市} 全屋定制 团购` | 公司名、城市、平台、是否有抖音/小红书号 |
| 跨境卖家 | `{城市} 跨境电商 公司`、`{品类} 独立站`、`雨果网 {品类} 卖家` | 公司名、SKU 数、是否有英文站 |
| 律所 | `{城市} 律师事务所 主任`、`{城市} 律所 公众号` | 律所名、主任姓名 |
| 本地生活 | `{城市} 少儿培训 抖音团购`、`高德地图 {城市} 健身` | 门店名、评分、评论数 |
| 制造 | `{城市} 工业设备 厂家`、`{品类} 出口商 1688` | 公司名、是否有出口资质 |

**导入格式**（`python cli.py leads import <csv>` 需要 5 列）：
```csv
公司,行业,城市,联系人,痛点
上海XX装饰工程有限公司,家装,上海,王总,抖音200条视频无一条挂链接
```

**预计产出**：每个行业每天 2-3 小时，可整理 30-50 家有效线索。够跑 3 天。

### 路线 2：地图与生活服务平台（免费，精准）
- 高德/百度地图搜行业关键词 → 按城市抓取 → 拿到电话（企业电话）
- 大众点评/美团 → 拿到门店、评分、评论数（评论数是判断"是否需要内容"的代理指标）
- 企查查/天眼查免费版 → 拿到法人、成立时间、参保人数（参保人数 = 公司规模）

**关键判断规则**（用可获取的公开数据代替"痛点访谈"）：
| 公开数据 | 推断的痛点 |
|---|---|
| 参保人数 < 5 | 无专职市场，客单价可能不高 → C 档 |
| 参保人数 5-30 | 有销售无市场，转化靠老板个人 → **A 档** |
| 抖音粉丝 > 1 万但无挂链 | 内容已有投入，缺转化路径 → **A 档** |
| 公众号 3 个月未更新 | 有预算但不投，决策者不在场 → B 档 |
| 官网无 Schema / 无 HTTPS | 完全没被 AI 收录 → A 档（GEO 需求最强） |
| 招聘 JD 写"熟练 Excel" | 流程未数字化，AI 落地空间大 → A 档 |

### 路线 3：转介绍（成本最低，量最小，第 1 天就该启动）
见 `03_获客/03_转介绍机制.md`。

### 路线 4：付费渠道（第 3 个月后）
- 抖音/小红书信息流（先测 3000 元/2 周，跑通再加）
- 行业展会名单（上海周边展会很多，展会名录本身就是名单）
- 平台接单（猪八戒、一品威客等）—— 单价被压但能填产能空档
- 本地商会/行业协会（上海徐汇一带，商会名录可以直接要）

## 三、名单质量标准（不要垃圾名单）

**一条线索合格的标准（4 条全中）**：
- [ ] 能定位到具体的人（不是"市场部"）
- [ ] 能看到他的内容/账号（说明他在线）
- [ ] 能说出一个可观察的信号（他有什么"做错"的地方）
- [ ] 他的行业在 ICP 前两位

**不合格的处理**：宁可 50 条精名单，不要 500 条广撒。
广撒的回复率通常是精名单的 1/5，而且会拉低账号权重（被大量拉黑）。

---

## 四、名单 → 触达 → 成交的期望值（务必有心理预期）

按本文件夹内的健康线（触达→回复 8%，回复→成交 20%）：

| 每日触达 | 30 天累计 | 预期对话 | 预期成交 | 预期收入（均单 3.5 万） |
|---|---|---|---|---|
| 60 条 | 1,800 | 144 | 29 | 101 万 |
| 100 条 | 3,000 | 240 | 48 | 168 万 |
| 20 条 | 600 | 48 | 10 | 35 万 |

**这张表是本项目最重要的财务模型。** 它说明：
- 每天 60 条 → 3 个月约 100 万（这是前 3 个月的主要收入来源）
- 要到 1000 万，第 3 个月后必须把这条线的规模再放大 3-5 倍，或者叠加订阅/课程

**所以"每天 60 条"不是建议，是数学要求。**

## 五、名单管理与隐私合规（必须遵守）

- 只用**公开商业信息**（企业公示、平台主页、官网、展会名录）
- **不抓取个人身份证号、家庭住址、私人手机号**；联系方式优先用企业公示电话、官方邮箱、平台私信
- 首次触达必须表明身份和来意（"我是谁"可以放最后，但不能不写）
- 对方明确表示"不要再联系" → **立即停止**，并记录到排除名单
- 遵守《个人信息保护法》：处理个人信息需告知用途；拒绝营销的可加入营销拒绝名单
- 商业信息批量采集用于商业营销，需评估是否构成"不正当竞争"——
  **保守做法：名单用实体特征描述，落到具体主体时通过人工核验**（这也是 `01_引擎` 默认用"实体特征"而非编造公司名的原因）

**一条自保原则**：宁可慢，不可违规。一起个人信息纠纷足以让 GM 层面的项目停摆。
