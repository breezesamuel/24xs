# Chrome Web Store 上架包 — BDS Toolbox v1.0.0

**产物**: `bds-toolbox-v1.0.0.zip`（19KB，manifest v3，零权限请求）

**上架步骤（你 15 分钟）**：
1. 注册 Chrome Web Store 开发者账号（一次性 $5）：https://chrome.google.com/webstore/devconsole
2. 上传 zip → 填 listing（文案见下）→ 提交审核（通常 1-3 天）
3. 过审后同样物料可一键复投 Edge Add-ons（免费）与 Firefox AMO（免费）

**Listing 文案**：
- **Name**: BDS Toolbox — 508 AI micro-calculators
- **Short desc**: Instant answers for everyday pains. 508 micro-calculators, five languages, free 10 uses per tool.
- **Category**: Productivity → Tools
- **Screenshots**: 插件需在浏览器内截图（popup 1280x800 规范）——上架时用 Edge 打开 bds-toolbox 目录加载后截 2 张（popup 空态/搜索态），素材齐后 5 分钟可交
- **Privacy tab**: 单一用途声明（本地搜索+跳转自家站点），不收集任何用户数据（manifest 零权限是最强隐私背书）

**价值逻辑**：插件商店是自带搜索流量的分发渠道；每份安装都是进入 5775 工具站的入口，
付费墙（10 次免费）在站点端承接。无广告无追踪 = 高过审率。

**后续版本路线**：v1.1 右键菜单"用 BDS 算这个"（选中文本直接进计算器）；v1.2 新标签页皮肤（站点导航位）。
