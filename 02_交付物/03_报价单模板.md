# 报价单模板（可直接改品牌名后使用）

> 依据：`01_引擎/config.py PRICING`（2026 年 6-9 月国内公开报价行情）
> 定价原则：**按资产交付计件，不按人天开口**。客户要的是结果，不是工时。

## 二、报价单正文模板

```
────────────────────────────────────────────
        XX 集团 · AI 落地与 GEO 全案 报价单
────────────────────────────────────────────

致：{客户公司}    报价编号：{日期}-GEO-{序号}
     报价有效期：自出具日起 15 个自然日

一、现状诊断结论（我们看到的，不是我们自己说的）
   · 贵司在 {平台A/B/C} 的 {N} 个真实客户问题中被提及 {X} 次（提及率 {X}%）
   · 首选率 {Y}%——即 AI 第一个推荐的是 {竞品}
   · 最大短板：{平台} 的 {意图} 类问题，提及率仅 {Z}%
   · 结论：以贵司当前状态，潜在客户向 AI 咨询时，看到的不是贵司。

二、我们要解决什么
   1. 让 AI 在「{3-5 个核心问题}」上能正确描述贵司，且描述与事实一致
   2. 让 {N} 个高价值客户问题被 {M} 个 AI 平台正确引用
   3. 把上述结果接到贵司的线索系统，可归因到成交

三、交付物清单（逐项验收，不含口头承诺）
   □ 1. 现状诊断报告（≥ 60 题 × 8 平台实测数据 + 短板排序）
   □ 2. FAQ 知识库 {30} 条（官网部署 + 结构化标记）
   □ 3. 服务/参数对比表 {5} 张
   □ 4. 深度白皮书 {1} 篇（≥ 8000 字，含独家数据）
   □ 5. Schema.org 结构化数据 {1} 套（首页 + {5} 个服务页）
   □ 6. 第三方权威信源 {8} 个（含可核验 URL 清单）
   □ 7. 月度监测报告 {12} 份（含竞品异动告警）
   □ 8. 月度迭代内容 {12-24} 篇
   □ 9. 专属看板（数据留存，可随时回溯原始探测数据）

四、周期与节奏
   第 1-2 周  诊断与问题库构建      → 交付《现状诊断报告》
   第 3-6 周  内容资产建设与部署    → 交付 FAQ / 对比表 / Schema
   第 5-10 周 第三方信源分发        → 交付《信源投放清单》
   第 3-12 周 监测与迭代（持续）    → 每月《监测与归因报告》

五、报价
   项目总额：人民币 {XXX} 元（大写：{XXX}）
   付款方式：
     · 合同签订后 5 个工作日内付 40% 启动款
     · 诊断报告交付后付 30%
     · 首月监测报告交付后付 30%
   税费：含 6% 增值税专用发票
   有效期：15 个自然日

六、验收标准（不达标免费返工，不达标不计入尾款）
   1. 诊断报告：覆盖 ≥ 5 平台 × ≥ 60 问题 × ≥ 5 意图，原始数据可导出
   2. FAQ：≥ 30 条全部上线并可被搜索引擎收录
   3. Schema：`python -m json.tool` 校验通过，首页与服务页均部署
   4. 信源：≥ 8 个，其中权威站点 ≥ 3 个，附 URL 清单
   5. 月报：含提及率/首选率/有效线索/单线索成本四项，逐月可对比

七、我们不承诺什么（写清楚，比什么都重要）
   · 不承诺具体排名或「一定第一」
   · 不承诺具体线索数量（获客结果受贵司产品、价格、销售能力共同影响）
   · 不使用任何灰帽手段（伪造引用、诱导提问、刷数据），本条写入合同

八、报价有效期与备注
────────────────────────────────────────────
```

## 三、议价应对（客户压价时的标准动作）

| 客户说 | 你回 | 逻辑 |
|---|---|---|
| "太贵了" | "拆开看：诊断 {X} 元、知识库 {Y} 元、信源 {Z} 元、监测 {W} 元。你可以只买前两项，报价 {X+Y} 元，但信源和监测效果会打折。" | 用拆分代替降价，保住毛利 |
| "某某家报价一半" | "他们的报价里没有第三方信源投放和月度监测。我们这一项占 {比例}%。你可以让他们报价里写明包含什么，我们写得很细就是为了这个。" | 把价格战拉回交付对比 |
| "先做个效果看看" | "可以。诊断阶段 {X} 元就出结论。如果做完发现你不适合做，我们自己会告诉你不做。" | 用低门槛引流品换对话 |
| "能不能保证效果" | "我不能保证排名，也不能保证线索数——那取决于你的产品和销售。但我可以保证：过程指标全部写进合同，不达标免费返工。" | **绝不承诺效果数字**，这是行业底线 |
| "我先考虑一下" | "理解。我把诊断报价单和一页纸的方法论发你，不催你。什么时候想看清楚现状，随时找我，一周出结果。" | 给台阶，不逼单 |

**定价纪律**：
1. 报价单永远书面，不口头报价（口头报价是所有扯皮的起点）。
2. **不主动降价**。降价只能用来换条件（缩短周期 / 缩范围 / 提高预付比例 / 换案例授权）。
3. 第一单可以做 30% 的"新客户价"，但**只有一次**，且必须在合同里写明。
4. 第二单起恢复标准价。低价客户会带来低价转介绍客户。

## 四、成本核算（每个报价发出前跑一次）

```
python cli.py money status
# 或在 Python 里：
from finance import delivery_cost, quote_floor
c = delivery_cost(pm_days=6, arch_days=8, writer_days=12, dev_days=10, ops_days=10, tokens_k=200)
print(c)              # 逐项成本 + 直接成本 + 管理准备 + 合计
print(quote_floor(c))  # 毛利 55% 下的报价下限
```

**规则：报价不得低于 `quote_floor()`。** 低于就是赔钱，赔钱最多做 2 个案例。
