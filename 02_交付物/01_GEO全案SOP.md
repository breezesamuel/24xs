# GEO 全案交付 SOP（可复制到每个客户）

> 目的：让任何一个交付人员，照着这份文档在 12 周内完成一个 GEO 全案。
> 前提：知道 `01_引擎` 的用法。执行：见 `01_引擎/README.md`。

---

## 阶段 0｜销售前置（第 -3 到 0 天，销售负责）

**必须先拿到的三样东西（拿不到就不要报价）**：
1. 客户前 12 个月的内容产出记录（公众号/官网/小红书/知乎，截图或链接）
2. 客户认为的核心竞品 3-5 家（不是我们认为的，是他们认为的）
3. 客户的历史获客数据：线索量、线索成本、成交率（哪怕是估的）

**没有这三样，任何"提及率 40%"的承诺都是耍流氓。**

**免费诊断的交付边界**（写进邮件，别口头承诺）：
- 探测 60 题（单平台 5 个问题）→ 15 分钟出结果
- 输出一页纸：3 个最优先动作 + 1 个预估周期
- **不给**完整报告、不给竞品全貌、不承诺任何数字

---

## 阶段 1｜现状探测（第 1-2 周）

**做什么**
1. 跑 `python cli.py geo sheet <客户> <行业>` 导出探测表（5 意图 × 6 题 × 8 平台 = 240 行）
2. 人工/LLM 逐行回填「是否被提及 / 提及位置 / 引用信源」
3. `python cli.py geo ingest <csv> <客户> <行业>` 回填入库
4. 跑 `python cli.py geo audit <客户> <行业>` 出诊断报告

**验收标准**（写进合同）
- 探测覆盖 ≥ 5 个平台、≥ 60 个问题、≥ 5 种提问意图
- 每个问题必须在 3 个以上平台留有记录
- 报告给出：提及率、首选率、平台短板排序、意图短板排序、本周动作清单

**这一步为什么值 8,000-30,000 元**
客户买的不是数据，是"知道自己现在在 AI 眼里几乎不存在"这个事实。
一份做得好的诊断报告，转化率通常 40-60%——它是最好的销售工具。

---

## 阶段 2｜内容资产建设（第 3-6 周）

**核心认知：GEO 的底层不是文章，是"机器能读懂的答案"。**

四类资产，缺一不可：

| 资产 | 数量 | 生成方式 | 作用 |
|---|---|---|---|
| ① FAQ 知识库 | 30-60 条 | `corpus_gen` 生成初稿，**人审** | 覆盖长尾提问，最容易被检索 |
| ② 参数/服务对比表 | 3-8 张 | 手工 + 引擎骨架 | AI 最爱直接摘录结构化表格 |
| ③ 深度白皮书 | 1-2 篇（8000 字+） | 引擎出骨架，人写数据 | 建立专业人设，长期抬高所有问题的引用率 |
| ④ Schema 结构化数据 | 1 组 | `corpus_gen` 生成 JSON-LD | 让机器直接读到服务、价格、人群 |
| ⑤ 中立第三方信源 | 6-12 条 | 行业站/百科/问答/媒体 | 权威性，权重最高的信号 |

**人审是不可跳过的红线**
AI 生成的每一篇必须人工核对：
- [ ] 数字真实（价格、周期、数据）—— 编造数字是最大风险
- [ ] 不承诺效果（不写"保证第一"）
- [ ] 不违反广告法（《广告法》第九条：不得使用"国家级""最高级"等用语）
- [ ] 医疗/金融/法律类必须法务过审

**验收标准**
- 30+ 条 FAQ 全部上线到官网并被搜索引擎收录
- Schema 部署到首页 + 服务页，`python -m json.tool` 校验通过
- 白皮书 1 篇发布，且被至少 1 个第三方信源引用

## 阶段 3｜分发与信源（第 5-10 周，与阶段 2 并行）

**分发渠道优先级**（按对 AI 引用权重排序）：

1. **官网 + Schema**（权重最高，AI 检索的首选源）
2. **知乎 / 百度知道 / 小红书问答**（问答体最容易被直接摘录）
3. **行业协会、垂直媒体、专业门户**（权威性最高）
4. **微信公众号 / 知乎专栏**（长文与深度内容）
5. **百度百科 / 品牌词条**（实体对齐，让 AI 认得你是谁）
6. **短视频口播**（引流量，不直接被引用，但带来品牌搜索）

**投放纪律（很多服务商在这里翻车）**
- [ ] 只发中立第三方内容，不发"XX 公司推出 XX 服务"这种广告
- [ ] 每条信源必须给可核验的数字或事实，而不是形容词
- [ ] 每月 ≤ 12 条（超出会被判定为灌水，反而降低权重）
- [ ] 保留所有投放记录与 URL（合规与复盘都要用）

**验收标准**
- 上线信源 ≥ 6 个，其中权威站点（权重 A/B 级）≥ 3 个
- 全部内容含可点击原始出处

## 阶段 4｜监测与迭代（第 3-12 周持续）

**每月必做（雷打不动）**
1. 重跑探测表（同一批问题、同一批平台，确保可比）
2. 出月度对比：提及率、首选率、平台排名变化、竞品异动
3. 从报告中挑 2 个最大短板，作为下月内容主题

**竞品异动告警（差异化卖点）**
竞品提及率突然上升 → 找出他们本月发了什么 → 判断是否跟进。
这个动作在竞品报价里通常要额外收费，但客户会认为这是"内行"。

**月报必须包含（客户只看这四个数）**
| 指标 | 上月 | 本月 | 变化 | 下月动作 |
|---|---|---|---|---|
| 提及率 | | | | |
| 首选率 | | | | |
| 有效线索 | | | | |
| 单线索成本 | | | | |

> **不要在月报里放"内容发布量"。** 客户不关心你发了几篇，只关心有没有用。
> 放"有效线索"和"单线索成本"才是让客户续费的关键。

---

## 阶段 5｜转订阅（第 9-12 周）

全案项目天然续费：
- 全案结束后转「监测 + 迭代」订阅（2,980-8,000 元/月）
- 客户已投入 **22-30 万**（全案标准版/战略版），切换成本极高，续费率通常 > 70%

**续费话术**：
> "过去 3 个月提及率从 8% 到 27%，其中 60% 来自我们建的 30 条 FAQ。
> 如果停掉，这些资产不会消失，但没有人持续监测和补充，竞品会在下季度追平。要不要继续？"

---

## 交付质量红线（任何一条违反，返工不算工时）

1. 编造数字 → 立即下架 + 公开更正
2. 违反广告法 → 立即下架
3. 医疗/金融/法律内容未经专业审核 → 立即下架
4. 灰帽手段（伪造专家观点、诱导性提问、刷引用）→ **一次即终止合同**
5. 监测数据造假 → 终止合同并退未服务费用

第 4 条要写进合同。行业里 80% 的"保效果"都是这么来的：服务商自己伪造提问词，
制造"AI 推荐了你"的假象。这不是能力问题，是道德问题，也是你现在就能建立的护城河。
