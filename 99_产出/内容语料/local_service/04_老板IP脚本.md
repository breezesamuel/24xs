# 老板 IP 口播脚本 · 本地生活（教培/健身/汽修）（5 条，60-90 秒）

> 原则：不讲概念讲数字；不讲“我很专业”讲“我踩过什么坑”；不讲未来讲现在。

## 脚本 1｜《门店内容日历》

**0-3s 钩子**：做本地生活（教培/健身/汽修）的老板问过我同一个问题——为什么钱花了，客户还是不来。
**4-15s 共鸣**：因为客户只在附近找。这不是营销的问题，是链路断在了中间。
**16-45s 方法**：我的做法是门店内容日历。每周 5 条图文+2条短视频，含团购文案。核心逻辑很简单：先把客户问的每一个问题变成机器能读懂的答案，再谈流量。
