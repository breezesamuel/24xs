### Turn Prompt Logic Into a Visible Execution Path.

Use visual building blocks and AI prompts to define how an app thinks, retrieves data, makes decisions, uses tools, asks for human input, and completes tasks. The logic stays visible, so teams can test, debug, deploy, and hand it off with confidence.

[Explore Workflow Studio](/workflows)

### Build Agents with Skills, Tools, and Knowledge

Build an agent by chatting or configuring it manually. Use it as an app, embed it into a website, or reuse it as an agent node inside a workflow.

[Learn How to Build an Agent](https://docs.dify.ai/en/cloud/use-dify/build/new-agent/build)

### Prepare the Context Your AI Apps Rely On.

Create repeatable pipelines for files, websites, online documents, and drives. Extract, clean, chunk, index, and test retrieval before the knowledge base is connected to agents or workflows.

[Explore Knowledge Pipeline](/rag)

### Bring Your AI Stack into One Workspace.

Install model providers, tools, data sources, and MCP integrations from the Marketplace or define your own. Teams can reuse approved plugins across apps instead of wiring each project from scratch.

[Visit the Marketplace](https://marketplace.dify.ai)

### Ship the Same Logic as an App, API, or Tool.

Publish Dify apps as hosted experiences, API endpoints, embeds, or MCP-compatible tools. Use logs, feedback, annotations, latency, and usage data to understand what happened and improve the app over time.

[See Publish Options](https://docs.dify.ai)
