## 一、这个文件夹到底有什么

### 1. 一个能跑的体检引擎（不是 PPT，不是计划）

`F:\2026\24xs\01_引擎\geo_health.py`

它回答一个具体问题：**当客户在 AI 里问「上海哪家口腔诊所好」，AI 会不会提到你？**

AI 回答问题靠三件事：抓得到你的网站、看得懂你是谁、抓得到你的问答。
引擎就测这三件事，每项都有可验证的技术依据（`robots.txt`、`JSON-LD`、`llms.txt`、`FAQPage`），不靠主观打分。

已修的真实缺陷（都会让客户白花钱，所以必须修）：

| 缺陷 | 后果 | 状态 |
|---|---|---|
| 不认 JSON-LD `@graph` | 15/21 家被误判「无结构化数据」 | 已修 |
| robots.txt 缺失判为「拦 AI」 | 全场打成 0 分 | 已修 |
| 只认 HTTP 200 | 华为/海尔等活站被判「官网无法访问」 | 已修 |
| 把 WAF 挑战页当官网内容 | 打分造假 | 已修（标记需人工，不绕过） |
| `HTTP 0` 说成「你网站打不开」 | 把我方网络问题算到客户头上 | 已修 |

## 四、1000 万到底要多少单（诚实测算）

| 假设 | 所需单量 |
|---|---|
| 全部 ¥1 | 10,000,000 |
| 全部 ¥9.9 | 1,010,101 |
| 全部 ¥99 | 33,445 |
| 全部 ¥2999 | 3,334 |
| 混合（80% ¥1 / 15% ¥9.9 / 4% ¥99 / 1% ¥2999） | 每千客户 ¥36,235 |

**混合模型下，276 个客户 = 1000 万。** 但这需要证明 4% 的人买 ¥99、1% 买 ¥2999 ——
这恰恰是**必须先有成交才能验证的事**，所以我不会把它当成已实现的结论。

真正诚实的说法：要 1000 万，靠 ¥1 需要 1000 万人，靠 ¥99 需要 3.3 万单。
唯一能同时成立的路径是**白标**（¥2999 × 3334 = 让 3334 家服务商去卖）。

## 五、已经拦在路上的真实障碍（不粉饰）

| 障碍 | 状态 | 影响 |
|---|---|---|
| 官网托管在 Vercel | **中国大陆被 DNS 污染 + IP 封锁** | 上海客户打不开；**支付宝异步通知也进不来** |
| 阿里云服务器 SSH | 公钥未授权 | 无法部署 |
| 服务器 443 关闭 | 无 HTTPS | 支付回调不安全 |
| 支付宝密钥 | 曾进入会话 | 收款前必须轮换 |
| 中文搜索引擎 | 结果由 JS 渲染 / 跳转包装 | 无法规模化抓取名单 |
| `gsxt.gov.cn` 工信部 | 返 521 反爬 | 不硬绕 |

前两条是**唯一的硬阻塞**，且只需一条 SSH 授权命令就能解开。
