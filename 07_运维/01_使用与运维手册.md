## 二、每天自动跑（推荐）

### 方式 A：安装 Windows 计划任务（一次设置，永久生效）

```powershell
powershell -ExecutionPolicy Bypass -File "F:\2026\24xs\07_运维\install_daily_task.ps1"
```

会创建一个名为 `AI_Engine_Daily` 的计划任务，每天 08:50 运行。
日志写入 `F:\2026\24xs\07_运维\daily.log`。

**验证**：
```powershell
powershell -ExecutionPolicy Bypass -File "F:\2026\24xs\07_运维\run_daily.ps1"
Get-Content F:\2026\24xs\07_运维\daily.log -Tail 20
```

### 方式 B：手动双击
```
F:\2026\24xs\07_运维\run_daily.bat
```

## 四、备份（数据库是唯一的复利存量，必须备份）

**必须备份**：`99_产出/_data/factory.sqlite3`
（里面是探测数据、潜客、内容索引、全部财务流水——丢了就要重新积累）

**自动备份**（`run_daily.ps1` 已内置，保留最近 30 天）：
```powershell
Copy-Item "F:\2026\24xs\99_产出\_data\factory.sqlite3" `
          "F:\2026\24xs\07_运维\backup\factory_$(Get-Date -Format yyyyMMdd).sqlite3"
```

**手动恢复到某一天**：
```powershell
Copy-Item "F:\2026\24xs\07_运维\backup\factory_20261015.sqlite3" `
          "F:\2026\24xs\99_产出\_data\factory.sqlite3" -Force
```

> **为什么这件事重要**：第 90 天时，你的 5000 条探测数据本身就是可以卖的东西
> （"你这个行业 AI 可见度的行业基准数据，全网只有我们有"）。
> 它不是日志，是资产。丢了等于把三个月的复利清零。

## 六、出问题时

| 现象 | 原因 | 处理 |
|---|---|---|
| 找不到文件 | 不在 `01_引擎` 目录运行 | `cd F:\2026\24xs\01_引擎` 后重试 |
| 中文乱码 | 终端编码 | 用记事本/VSCode 打开 .md 文件，或 `python -X utf8` |
| 文件名含斜杠报错 | 公司名里有 `/` | 引擎已自动转义（`config.safe_name`） |
| 数据库锁定 | 同时开了两个进程 | 关闭另一个再试 |
| 计划任务不运行 | 执行策略 | 用方式 B 的 .bat 手动触发，或用 `-ExecutionPolicy Bypass` |
| 探测器报告为"无数据" | 还没跑 probe 或导入探测表 | `python cli.py geo audit <客户> <行业>` |

**任何问题都先看**：`99_产出/报告/最新看板.md`——
它会告诉你钱、漏斗、资产三个数，是唯一需要做决策的页面。
