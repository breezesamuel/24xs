数据流

  1. 用户通过前端页面发起请求
  2. API 层接收请求，进行身份验证
  3. 业务层处理业务逻辑（权限校验、积分扣减等）
  4. 数据层读取/写入数据
  5. 验证层确保数据完整性
  6. 返回结果给前端

支付流程

  1. 用户选择资产，点击购买
  2. 系统创建订单，生成支付链接
  3. 用户完成支付
  4. 支付平台回调 Webhook
  5. 系统验证签名，更新订单状态
  6. 触发交付流程，生成下载链接
  7. 发送通知邮件给用户

订阅流程

  1. 用户选择套餐，点击订阅
  2. 系统创建订阅订单
  3. 用户完成支付
  4. 系统激活订阅，发放积分
  5. 每月自动重置积分额度
  6. 到期前发送续费提醒
