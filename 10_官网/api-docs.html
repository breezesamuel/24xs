API 使用文档

基础 URL: https://geo-audit-24xs.vercel.app

认证

所有 API 请求需要在 Header 中携带客户 ID：

x-customer-id: your_customer_id

资产 API

GET
/api/assets
获取资产列表
参数类型必填描述
limitnumber否返回数量，默认 100
offsetnumber否偏移量，默认 0
{
  "ok": true,
  "total": 1056693,
  "data": [...]
}
GET
/api/search
全文搜索资产
参数类型必填描述
qstring是搜索关键词
typestring否资产类型过滤
limitnumber否返回数量，默认 50

验证 API

POST
/api/verify
验证资产 Proof
{
  "proof": "sha256_hash",
  "data": { ... }
}
{
  "ok": true,
  "data": {
    "match": true,
    "type": "direct",
    "computed": "sha256_hash"
  }
}

定价 API

GET
/api/pricing
获取定价信息
参数类型必填描述
actionstring否calculate/compare/estimate
tierstring否套餐层级
qtynumber否数量

购买 API

POST
/api/purchase
发起购买
{
  "asset_id": "V-20261003-001234",
  "amount_cny": 500.00
}
{
  "ok": true,
  "data": {
    "checkout_url": "https://...",
    "purchase_id": "P-xxx"
  }
}

错误码

状态码描述
200成功
400请求参数错误
401未授权
402需要支付（积分不足）
403禁止访问（订阅过期）
404资源不存在
429请求过于频繁
500服务器错误
